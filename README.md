## Current Work

**Salesforce · Security Data Platform · Oct 2022 – Present**

- Technical lead for migrating a multi-TB security ETL platform from AWS Glue to Spark on Kubernetes: 34 pipelines, 210+ jobs, zero data loss.
- Replaced Glue bookmarks with a DynamoDB-backed incremental file tracker for ~1M S3 objects, plus vanilla Spark schema resolution to keep Glue-level parity.
- Rebuilt the Vulnerability Data API in Go on an Iceberg/S3 lakehouse with Redis/ElastiCache. Serves 40+ security APIs.
- Built SLAMS, a contract-driven SLA service for availability, freshness, and latency. Used on 25+ pipelines across Security, Data Cloud, and other teams.
- Rolling upgrade of a self-managed Splunk Enterprise cluster (8.x → 9.x) processing 252 TB/day, with full data retention.
